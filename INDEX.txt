EXTENDING THE SCREENSAVER
═══════════════════════════════════════════════════════════════════════════════

Adding a new clock style is simple:

1. Create YourClock.cs:

   public class BauhausClockYourStyle : BauhausClockBase
   {
       public override string ClockType => "YourStyle";
       
       public BauhausClockYourStyle(Point position, int size) 
           : base(position, size) { }
       
       public override void Render(Graphics g)
       {
           // Your custom rendering code
       }
   }

2. Add to ScreensaverForm.InitializeClocks():

   if (config.ShowYourStyleClocks)
       availableTypes.Add(typeof(BauhausClockYourStyle));

3. Add configuration property:
   • BauhausConfig: public bool ShowYourStyleClocks { get; set; }
   • BauhausSettingsForm: Add checkbox for your style

4. Rebuild and test!
