═══════════════════════════════════════════════════════════════════
 FOR USERS (Installing Pre-Built Screensaver)
═══════════════════════════════════════════════════════════════════

1. INSTALL
   • Right-click "BauhausScreensaver.scr"
   • Select "Install"
   • Windows will open Screen Saver Settings
   • Click "OK" to confirm

2. CONFIGURE
   • Open Windows Settings
   • Navigate to: Personalization → Lock screen → Screen saver settings
   • Select "BauhausScreensaver" from dropdown
   • Click "Settings..." button
   • Choose your preferred options:
     ✓ Clock styles (Analog, Digital, Abstract)
     ✓ Number of clocks (1-12)
     ✓ Background color
     ✓ Animation speed
   • Click "OK"

3. TEST
   • In Screen Saver Settings, click "Preview"
   • Or right-click BauhausScreensaver.scr → "Test"
   • Press any key or move mouse to exit

═══════════════════════════════════════════════════════════════════
 FOR DEVELOPERS (Building from Source)
═══════════════════════════════════════════════════════════════════

METHOD 1: Visual Studio (Recommended)
────────────────────────────────────
1. Open "BauhausScreensaver.csproj" in Visual Studio
2. Set configuration to "Release"
3. Build → Build Solution (Ctrl+Shift+B)
4. Navigate to: bin\Release\net48\
5. Rename "BauhausScreensaver.exe" → "BauhausScreensaver.scr"
6. Right-click .scr file → Install

METHOD 2: Command Line (PowerShell)
────────────────────────────────────
cd C:\Users\magnus.sandstrom\Code\Repo\bauhaus_clock
dotnet build -c Release
cd bin\Release\net48
ren BauhausScreensaver.exe BauhausScreensaver.scr

METHOD 3: Manual Compilation (csc.exe)
────────────────────────────────────
csc.exe /target:winexe /out:BauhausScreensaver.scr ^
  /reference:System.Windows.Forms.dll ^
  /reference:System.Drawing.dll ^
  /reference:System.Xml.dll ^
  /optimize+ ^
  Program.cs BauhausConfig.cs BauhausClockBase.cs ^
  BauhausClockAnalog.cs BauhausClockDigital.cs ^
  BauhausClockAbstract.cs ScreensaverForm.cs ^
  BauhausSettingsForm.cs

═══════════════════════════════════════════════════════════════════
 COMMON ISSUES
═══════════════════════════════════════════════════════════════════

Q: Screensaver won't install?
A: Ensure file extension is .scr (not .exe)
   Run as Administrator if copying to System32

Q: Blank screen when running?
A: Open settings and enable at least one clock style
   Check that background color isn't pure black

Q: High CPU usage?
A: Reduce number of clocks in settings
   Lower animation speed

Q: Settings not saving?
A: Check permissions for %APPDATA%\BauhausScreensaver\
   Create folder manually if needed

═══════════════════════════════════════════════════════════════════
 CUSTOMIZATION
═══════════════════════════════════════════════════════════════════

To add your own clock style:

1. Create new class inheriting BauhausClockBase
2. Implement Render() method
3. Add to factory in ScreensaverForm.InitializeClocks()
4. Rebuild project

Example template provided in BuildInstructions.txt
